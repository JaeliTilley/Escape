# AI Usage Notes
The assignment asks for notes on where and how AI was used. I used AI to help with coding details and troubleshooting errors while creating the game.
Tool
Claude was used 
# Where it was used

    Coding and troubleshooting: Claude helped me with coding details and errors while I was implementing the game. I reviewed the suggestions, applied the fixes, and tested the game myself to make sure everything worked correctly.
    Game implementation: I used Claude as a coding reference when I needed help understanding how to create or fix certain scripts and gameplay features.
    No other AI use: I did not use AI to create the game concept, make my design decisions, choose my assets, test the game, record the gameplay video, or complete the final submission.

# What I did

    Wrote the original game design and one-page concept.
    Set up the Unity project and imported the scripts.
    Implemented and organized the game in Unity.
    Made the gameplay and design decisions.
    Downloaded the Kenney Tiny Dungeon art pack and replaced the placeholder sprites using Unity’s Inspector.
    Tested the game and fixed issues myself, using Claude only for help understanding coding errors and possible solutions.
    Tuned the gameplay mechanics and made sure the controls and interactions worked.
    Recorded the gameplay video using OBS.
    Created the final documentation and prepared the project for submission.
